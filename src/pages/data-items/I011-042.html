I011/042

Calculated Position in Cartesian Co-ordinates Hesaplanan Kartezyen Koordinat Konumu

Fixed Length — 4 Octets Sabit Uzunluk — 4 Oktet

Purpose Amaç

Calculated position of a target expressed in Cartesian co-ordinates (X/Y), relative to a system reference point. Unlike I011/041 which provides position in WGS-84 geodetic co-ordinates (latitude/longitude), this data item uses a local flat-earth Cartesian co-ordinate system centred on an agreed reference point — typically the Airport Reference Point (ARP). The X axis points East and the Y axis points North. Bir hedefin, sistem referans noktasına göre Kartezyen koordinatlarla (X/Y) ifade edilen hesaplanmış konumu. WGS-84 jeodezik koordinatlarında (enlem/boylam) konum sağlayan I011/041'in aksine, bu veri öğesi üzerinde anlaşılmış bir referans noktası merkezli yerel düz-dünya Kartezyen koordinat sistemi kullanır — genellikle Havalimanı Referans Noktası (ARP). X ekseni Doğu'yu, Y ekseni Kuzey'i gösterir.

Key concept: The Cartesian representation is particularly useful for surface movement displays, where distances in metres are more intuitive than lat/long degrees. The reference point must be pre-agreed between the data sender and receiver — it is not transmitted within the data item itself. Temel kavram: Kartezyen gösterim, metre cinsinden mesafelerin enlem/boylam derecelerine göre daha sezgisel olduğu yüzey hareketi görüntülerinde özellikle kullanışlıdır. Referans noktası veri gönderici ve alıcı arasında önceden kararlaştırılmış olmalıdır — veri öğesinin içinde iletilmez.

Structure Yapı

Octet Oktet Field Alan Bits Bitler Description Açıklama
1–2 X Component 16 (bit 32–17) X component (East–West), 16-bit signed integer in two's complement. Positive values indicate East of reference point. X bileşeni (Doğu–Batı), 16-bit işaretli tamsayı, ikiye tümleyen. Pozitif değerler referans noktasının Doğu'sunu gösterir.
3–4 Y Component 16 (bit 16–1) Y component (North–South), 16-bit signed integer in two's complement. Positive values indicate North of reference point. Y bileşeni (Kuzey–Güney), 16-bit işaretli tamsayı, ikiye tümleyen. Pozitif değerler referans noktasının Kuzey'ini gösterir.

Hex Example Hex Örneği

Scenario: A target located 500 metres East and 1200 metres North of the airport reference point. Senaryo: Havalimanı referans noktasının 500 metre Doğu'sunda ve 1200 metre Kuzey'inde bulunan bir hedef.

Step 1 — Encode X Component Adım 1 — X Bileşeni Kodlama
X = 500 m → 500 × 1 = 500 → 0x01F4 → 0000 0001 1111 0100
Step 2 — Encode Y Component Adım 2 — Y Bileşeni Kodlama
Y = 1200 m → 1200 × 1 = 1200 → 0x04B0 → 0000 0100 1011 0000
Step 3 — Final Encoded Value Adım 3 — Son Kodlanmış Değer
I011/042 = 0x01F4 04B0 → 0000 0001 1111 0100 0000 0100 1011 0000

Decoding: To decode, split the 4 octets into two 16-bit signed integers. For 0x01F4 04B0: X = 0x01F4 = 500 m (East), Y = 0x04B0 = 1200 m (North). Negative values (e.g., 0xFE0C = -500) indicate West (X) or South (Y) of the reference point. Çözümleme: Çözümlemek için 4 okteti iki adet 16-bit işaretli tamsayıya bölün. 0x01F4 04B0 için: X = 0x01F4 = 500 m (Doğu), Y = 0x04B0 = 1200 m (Kuzey). Negatif değerler (örn. 0xFE0C = -500) referans noktasının Batı'sını (X) veya Güney'ini (Y) gösterir.

Important Notes Önemli Notlar

Reference point agreement: The origin (0, 0) of the Cartesian co-ordinate system is not transmitted in this data item. Both the sender and receiver must agree on the reference point (typically the ARP) beforehand. If the reference points differ, all position data will be systematically offset. Referans noktası anlaşması: Kartezyen koordinat sisteminin orijini (0, 0) bu veri öğesinde iletilmez. Hem gönderici hem alıcı referans noktası (genellikle ARP) üzerinde önceden anlaşmış olmalıdır. Referans noktaları farklı olursa, tüm konum verileri sistematik olarak kaymış olacaktır.

Range limitation: With a 16-bit signed integer and LSB of 1 metre, the maximum representable distance is approximately ±32.7 km from the reference point. Targets beyond this range cannot be encoded in this data item. For large airports with distant approach paths, verify that this range is sufficient. Aralık sınırlaması: 16-bit işaretli tamsayı ve 1 metre LSB ile temsil edilebilir maksimum mesafe referans noktasından yaklaşık ±32,7 km'dir. Bu aralığın ötesindeki hedefler bu veri öğesinde kodlanamaz. Uzak yaklaşma yollarına sahip büyük havalimanları için bu aralığın yeterli olduğundan emin olun.

Tip: This data item is especially useful for surface movement displays (A-SMGCS HMI), where targets on runways, taxiways and aprons need to be plotted in a local co-ordinate system. The 1-metre resolution provides sufficient accuracy for surface surveillance applications. İpucu: Bu veri öğesi, pistler, taksi yolları ve apronlardaki hedeflerin yerel bir koordinat sisteminde çizilmesi gereken yüzey hareketi görüntülerinde (A-SMGCS HMI) özellikle kullanışlıdır. 1 metre çözünürlük, yüzey gözetim uygulamaları için yeterli doğruluk sağlar.
