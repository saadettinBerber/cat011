I011/010

Data Source Identifier Veri Kaynağı Tanımlayıcı

Fixed Length — 2 Octets Sabit Uzunluk — 2 Oktet

Purpose Amaç

Identification of the system sending the data. Every CAT011 message must include this data item. It uses the standard ASTERIX SAC/SIC pair to uniquely identify the data source — typically the A-SMGCS server at a specific airport. Veriyi gönderen sistemin tanımlanması. Her CAT011 mesajı bu veri öğesini içermelidir. Veri kaynağını benzersiz şekilde tanımlamak için standart ASTERIX SAC/SIC çiftini kullanır — genellikle belirli bir havalimanındaki A-SMGCS sunucusu.

Key concept: SAC (System Area Code) identifies the geographical area or country, while SIC (System Identification Code) identifies the specific system within that area. Together they form a unique address. Temel kavram: SAC (Sistem Alan Kodu) coğrafi bölgeyi veya ülkeyi tanımlarken, SIC (Sistem Tanımlama Kodu) o bölgedeki belirli sistemi tanımlar. Birlikte benzersiz bir adres oluştururlar.

Structure Yapı

Octet Oktet Field Alan Bits Bitler Description Açıklama
1 SAC 8 (bit 16–9) System Area Code — identifies the geographical region or country of the data source Sistem Alan Kodu — veri kaynağının coğrafi bölgesini veya ülkesini tanımlar
2 SIC 8 (bit 8–1) System Identification Code — identifies the specific system within that area Sistem Tanımlama Kodu — o bölgedeki belirli sistemi tanımlar

Hex Example Hex Örneği

Scenario: An A-SMGCS server at Istanbul Airport, with SAC = 40 (Turkey region) and SIC = 1 (system #1). Senaryo: İstanbul Havalimanındaki bir A-SMGCS sunucusu, SAC = 40 (Türkiye bölgesi) ve SIC = 1 (sistem #1).

Step 1 — Encode SAC Adım 1 — SAC Kodlama
SAC = 40 → 0x28 → 0010 1000
Step 2 — Encode SIC Adım 2 — SIC Kodlama
SIC = 1 → 0x01 → 0000 0001
Step 3 — Final Encoded Value Adım 3 — Son Kodlanmış Değer
I011/010 = 0x28 0x01 → 0010 1000 0000 0001

Decoding: To decode, read the first octet as SAC and the second as SIC. For 0x28 0x01: SAC = 0x28 = 40, SIC = 0x01 = 1. Look up SAC 40 in the ASTERIX SAC table to determine the country/region. Çözümleme: Çözümlemek için ilk okteti SAC, ikinci okteti SIC olarak okuyun. 0x28 0x01 için: SAC = 0x28 = 40, SIC = 0x01 = 1. Ülkeyi/bölgeyi belirlemek için ASTERIX SAC tablosunda SAC 40'a bakın.

Important Notes Önemli Notlar

Note: The SAC/SIC combination must be unique within the ASTERIX network. If two A-SMGCS systems share the same SAC/SIC, message routing and data correlation will fail. Coordinate with EUROCONTROL for official SAC/SIC assignments. Not: SAC/SIC kombinasyonu ASTERIX ağı içerisinde benzersiz olmalıdır. İki A-SMGCS sistemi aynı SAC/SIC'i paylaşırsa, mesaj yönlendirme ve veri korelasyonu başarısız olur. Resmi SAC/SIC atamaları için EUROCONTROL ile koordine edin.

Tip: In a typical airport setup, the A-SMGCS server uses a single SAC/SIC for all its CAT011 output. Different services from the same server are distinguished by I011/015 (Service Identification), not by different SIC values. İpucu: Tipik bir havalimanı kurulumunda, A-SMGCS sunucusu tüm CAT011 çıktısı için tek bir SAC/SIC kullanır. Aynı sunucudan farklı servisler, farklı SIC değerleri ile değil, I011/015 (Servis Tanımlama) ile ayırt edilir.
