I011/000

Message Types Mesaj Tipleri

7 Transaction Types 7 İşlem Tipi

Overview Genel Bakış

Every CAT011 message contains a Message Type field (Data Item I011/000) that identifies the kind of transaction being transmitted. This field is mandatory — it must be present in every record. There are 7 defined message types, grouped into three functional categories. Her CAT011 mesajı, iletilen işlemin türünü tanımlayan bir Mesaj Tipi alanı (Veri Öğesi I011/000) içerir. Bu alan zorunludur — her kayıtta bulunmalıdır. Üç fonksiyonel kategoriye ayrılmış 7 tanımlı mesaj tipi vardır.

Functional Categories Fonksiyonel Kategoriler

Surveillance (Type 1) Gozetim (Tip 1)

The workhorse of CAT011. Target reports carry the fused track data — everything from position and velocity to identity and alerts. Sent continuously at the track update rate. CAT011'in temel mesajıdır. Hedef raporları, konumdan hız ve kimliğe kadar birleştirilmiş iz verisini taşır. İz güncelleme hızında sürekli gönderilir.

Flight Plan (Types 2–6) Uçuş Planı (Tip 2-6)

Five message types for flight plan lifecycle management: attach, detach, insert, suppress, and modify. These are event-driven — sent only when an operator or system takes action. Uçuş planı yaşam döngüsü yönetimi için beş mesaj tipi: bağlama, çözme, ekleme, silme ve değiştirme. Bunlar olay odaklıdır — yalnızca operatör veya sistem işlem yaptığında gönderilir.

Infrastructure (Type 7) Altyapı (Tip 7)

Holdbar status reports. Unlike other types, this has no track association — it reports the physical state of airport infrastructure (stop bar lights). Holdbar durum raporları. Diğer tiplerden farklı olarak iz ilişkisi yoktur — havalimanının fiziksel altyapısının (durdurma çubuğu ışıkları) durumunu raporlar.

Encoding Details Kodlama Detayları

The Message Type is encoded in Data Item I011/000 as a single unsigned byte (8 bits). It is a Fixed Length data item — always exactly 1 byte. The value directly represents the message type number (1–7). Values 0 and 8–255 are currently not defined and should be treated as reserved. Mesaj Tipi, I011/000 Veri Öğesi içinde tek bir işaretsiz bayt (8 bit) olarak kodlanır. Sabit Uzunluklu bir veri öğesidir — her zaman tam olarak 1 bayttır. Değer doğrudan mesaj tipi numarasını (1-7) temsil eder. 0 ve 8-255 arası değerler şu anda tanımlanmamıştır ve ayrılmış olarak değerlendirilmelidir.

I011/000 — 8-bit unsigned integer (1 octet) I011/000 — 8-bit işaretsiz tamsayı (1 oktet)

Important Notes Onemli Notlar

Tip: Message Type 1 (Target Report) typically includes most data items — position, velocity, identity, and even embedded flight plan data. Types 2–6 are lightweight and mainly carry the flight plan data items (I011/390) along with track identification (I011/161). İpucu: Mesaj Tipi 1 (Hedef Raporu) genellikle çoğu veri öğesini içerir — konum, hız, kimlik ve hatta gömülü uçuş planı verisi. 2-6 tipleri hafiftir ve esas olarak uçuş planı veri öğelerini (I011/390) ve iz tanımlayıcıyı (I011/161) taşır.

Note: Message Type 7 (Holdbar Status) is structurally different from all others — it has no track number, no position, no velocity. It only contains the data source (I011/010), message type (I011/000), and holdbar status indicators (I011/610). Not: Mesaj Tipi 7 (Holdbar Durumu) yapısal olarak diğer tümünden farklıdır — iz numarası, konum ve hız içermez. Yalnızca veri kaynağı (I011/010), mesaj tipi (I011/000) ve holdbar durum göstergeleri (I011/610) içerir.
