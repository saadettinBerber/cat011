I011/000

Message Type Mesaj Tipi

Fixed Length — 1 Octet Sabit Uzunluk — 1 Oktet

Purpose Amaç

This data item allows the identification of the type of message being transmitted. It is a mandatory field — every CAT011 record must contain it. The message type determines which data items are expected in the rest of the message and how the receiver should process it. Bu veri öğesi, iletilen mesajın türünü tanımlama olanaği sağlar. Zorunlu bir alandır — her CAT011 kaydı bunu içermelidir. Mesaj tipi, mesajın geri kalanında hangi veri öğelerinin beklendiği ve alıcının mesajı nasıl işlemesi gerektiği belirler.

Structure Yapı

Octet Oktet Field Alan Bits Bitler Description Açıklama
1 Message Type 8 (bit 8–1) Type of the message, encoded as unsigned integer (1–7) Mesaj tipi, işaretsiz tamsayı olarak kodlanır (1-7)

Defined Values Tanımlı Değerler

Value Değer Binary İkili Hex Meaning Anlam
1 0000 0001 0x01 Target Report (surveillance + flight plan + alerts) Hedef Raporu (gözetim + uçuş planı + alarmlar)
2 0000 0010 0x02 Manual Attachment of Flight Plan to Track Uçuş Planının İze Manuel Bağlanması
3 0000 0011 0x03 Manual Detachment of Flight Plan from Track Uçuş Planının İzden Manuel Çözülmesi
4 0000 0100 0x04 Insertion of Flight Plan Data Uçuş Planı Verisi Ekleme
5 0000 0101 0x05 Suppression of Flight Plan Data Uçuş Planı Verisi Silme

Note: Values 0 and 8–255 are not defined in the current edition (1.3). If received, they should be treated as reserved and the message should be flagged for investigation. Not: 0 ve 8-255 arası değerler güncel sürümde (1.3) tanımlanmamıştır. Alınırsa, ayrılmış olarak değerlendirilmeli ve mesaj inceleme için işaretlenmelidir.

Important Notes Önemli Notlar

Tip: In practice, the vast majority of CAT011 messages are Type 1 (Target Report). Types 2–6 are event-driven and relatively rare. Type 7 is periodic but only sent from airports with holdbar infrastructure. İpucu: Pratikte, CAT011 mesajlarının büyük çoğunluğu Tip 1 (Hedef Raporu) olur. Tip 2-6 olay odaklıdır ve nispeten nadirdir. Tip 7 periyodiktir ancak yalnızca holdbar altyapısına sahip havalimanlarından gönderilir.

Important: The message type fundamentally changes the expected content. A decoder must first read I011/000 to know how to interpret the remaining data items. For example, Type 7 will never contain position or velocity data. Önemli: Mesaj tipi, beklenen içeriği köklü şekilde değiştirir. Bir çözücünün kalan veri öğelerini nasıl yorumlayacağını bilmek için önce I011/000'i okuması gerekir. Örneğin, Tip 7 asla konum veya hız verisi içermeyecektir.
