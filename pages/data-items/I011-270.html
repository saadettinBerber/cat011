I011/270 Target Size & Orientation Hedef Boyutu & Yönelimi

Variable Length Değişken Uzunluk 1–3 Octets Oktet FX Extended Genişletilmiş UAP Block 3 — Altitude UAP Blok 3 — İrtifa

Purpose Amaç

Data Item I011/270 describes the physical dimensions and heading of a detected target on the airport surface. It provides the target's length, orientation (nose heading relative to geographical North), and width. This information is primarily derived from SMR (Surface Movement Radar) plot extraction and is used for target classification and display rendering on A-SMGCS controller screens. I011/270 veri öğesi, havalimanı yüzeyinde tespit edilen bir hedefin fiziksel boyutlarını ve yönünü tanımlar. Hedefin uzunluğunu, yönelimini (coğrafi Kuzey'e göre burun yönü) ve genişliğini sağlar. Bu bilgi öncelikle SMR (Yüzey Hareketi Radarı) plot çıkarımından elde edilir ve A-SMGCS (Gelişmiş Yüzey Hareketi Rehberlik ve Kontrol Sistemi) kontrolör ekranlarında hedef sınıflandırması ile görüntü oluşturma amacıyla kullanılır.

Bit Structure Bit Yapısı

LSB (Width) = 1 metre | Range: 0–127 m LSB (Genişlik) = 1 metre | Aralık: 0–127 m

Value Encoding Değer Kodlaması

LENGTH raw_value × 1 metre — 7-bit unsigned, range 0–127 m ham_değer × 1 metre — 7-bitlik işaretsiz, aralık 0–127 m
ORIENTATION raw_value × 360°/128 (≈ 2.8125°) — 7-bit unsigned, range 0°–357.19° ham_değer × 360°/128 (≈ 2.8125°) — 7-bitlik işaretsiz, aralık 0°–357.19°
WIDTH raw_value × 1 metre — 7-bit unsigned, range 0–127 m ham_değer × 1 metre — 7-bitlik işaretsiz, aralık 0–127 m
FX 0 = no further data, 1 = next octet follows 0 = başka veri yok, 1 = sonraki oktet devam eder

Each octet uses bits 8–2 for the data value and bit 1 as the FX extension indicator. To extract the value: shift the octet right by 1 bit (or integer-divide by 2). To extract FX: mask with 0x01. Her oktet, 8–2. bitleri veri değeri için, 1. biti ise FX uzatma göstergesi olarak kullanır. Değeri çıkarmak için: oktet 1 bit sağa kaydırın (ya da 2'ye tam bölün). FX'i çıkarmak için: 0x01 maskesi uygulayın.

  4. Octet 2: 0x41 = 0100 0001 Oktet 2: 0x41 = 0100 0001

  6. Check FX: Bit 1 = 1 → second extent (width) follows FX kontrolü: 1. bit = 1 → ikinci uzantı (genişlik) devam eder
  7. Octet 3: 0x78 = 0111 1000 Oktet 3: 0x78 = 0111 1000

Validation Rules Doğrulama Kuralları

  • Variable length: Minimum 1 octet (length only), maximum 3 octets (length + orientation + width). The FX bit in each octet determines whether the next octet is present. Değişken uzunluk: En az 1 oktet (yalnızca uzunluk), en fazla 3 oktet (uzunluk + yönelim + genişlik). Her oktetin FX biti, bir sonraki oktetin bulunup bulunmadığını belirler.
  • FX chain order: Extents must appear in order — orientation first, then width. You cannot have width without orientation. FX zincir sırası: Uzantılar belirli sırada yer almalıdır — önce yönelim, ardından genişlik. Yönelim olmadan genişlik bulundurulamaz.
  • Length range: 0–127 metres. A value of 0 may indicate that the target size is unknown or below the sensor resolution. Uzunluk aralığı: 0–127 metre. 0 değeri, hedef boyutunun bilinmediğini veya sensör çözünürlüğünün altında kaldığını gösterebilir.
  • Orientation range: 0° to 357.19°. The value 0 means the target nose is pointing North. Values increase clockwise. Yönelim aralığı: 0° ile 357.19° arasında. 0 değeri, hedef burnunun Kuzey'e baktığı anlamına gelir. Değerler saat yönünde artar.
  • Width range: 0–127 metres. Width should generally be less than or equal to length for aircraft; exceptions may occur for unconventional target shapes. Genişlik aralığı: 0–127 metre. Uçaklarda genişlik genellikle uzunluktan küçük ya da ona eşit olmalıdır; alışılmadık hedef şekillerinde istisnalar görülebilir.
  • Presence: This item is optional. Its presence is indicated by the FSPEC bit at UAP Block 3, position 6. Varlık: Bu öğe isteğe bağlıdır. Varlığı, UAP Blok 3'ün 6. konumundaki FSPEC biti ile belirtilir.

Related Items İlgili Öğeler

  • I011/042 — Calculated Position in Cartesian Coordinates: Provides the target location on the airport surface to which this size/orientation applies. Kartezyen Koordinatlarda Hesaplanan Konum: Bu boyut/yönelim bilgisinin geçerli olduğu, havalimanı yüzeyindeki hedef konumunu sağlar.
  • I011/170 — Track Status: Contains target classification flags (aircraft vs. vehicle) that help interpret the size values. İz Durumu: Boyut değerlerinin yorumlanmasına yardımcı olan hedef sınıflandırma bayraklarını (uçak mı araç mı) içerir.
  • I011/245 — Target Identification: The callsign can be cross-referenced with aircraft type databases to validate the reported dimensions. Hedef Kimliği: Callsign, bildirilen boyutları doğrulamak amacıyla uçak tipi veri tabanlarıyla çapraz referans olarak kullanılabilir.
  • I011/202 — Calculated Track Velocity: The velocity heading should correlate with the target orientation for moving targets. Hesaplanan İz Hızı: Hareket eden hedefler için hız yönü, hedef yönelimiyle örtüşmelidir.

Implementation Notes Uygulama Notları

  • Bit extraction pattern: For each octet, the data value is in bits 8–2 and the FX flag is bit 1. In code: value = octet >> 1 and fx = octet & 0x01. Bit çıkarım kalıbı: Her oktet için veri değeri 8–2. bitlerdedir; FX bayrağı ise 1. bittir. Kodda: value = octet >> 1 ve fx = octet & 0x01.
  • Orientation reference: Orientation is measured clockwise from geographical North (0° = North, 90° = East, 180° = South, 270° = West). This represents the direction the aircraft nose is pointing, not the direction of travel. Yönelim referansı: Yönelim, coğrafi Kuzey'den saat yönünde ölçülür (0° = Kuzey, 90° = Doğu, 180° = Güney, 270° = Batı). Bu değer, uçağın hareket yönünü değil, burunun baktığı yönü temsil eder.
  • Orientation resolution: The 2.8125° step size means that heading values are approximate. For precise heading information, refer to Mode-S derived data in I011/380 if available. Yönelim çözünürlüğü: 2.8125°'lik adım boyutu, yön değerlerinin yaklaşık olduğu anlamına gelir. Kesin yön bilgisi için, mevcut olması durumunda I011/380'deki Mode-S kaynaklı verilere başvurun.
  • Surface radar origin: This data item is primarily populated from SMR (Surface Movement Radar) target extraction. It may not be present for targets tracked solely via MLAT or ADS-B. Yüzey radarı kaynağı: Bu veri öğesi öncelikle SMR (Yüzey Hareketi Radarı) hedef çıkarımından doldurulur. Yalnızca MLAT veya ADS-B aracılığıyla izlenen hedefler için mevcut olmayabilir.
  • Display usage: The length, width, and orientation values are typically used to render a correctly sized and oriented target symbol on the A-SMGCS display. A simple rotated rectangle is the most common representation. Ekran kullanımı: Uzunluk, genişlik ve yönelim değerleri, A-SMGCS ekranında doğru boyut ve yönelimde bir hedef simgesi oluşturmak amacıyla kullanılır. En yaygın gösterim yöntemi döndürülmüş basit bir dikdörtgendir.
  • Vehicle vs. aircraft: Ground vehicles typically have smaller dimensions (length < 20 m). Unusually large dimensions for a vehicle-classified target may indicate misclassification. Araç - uçak ayrımı: Yer araçları genellikle daha küçük boyutlara sahiptir (uzunluk < 20 m). Araç olarak sınıflandırılmış bir hedefte alışılmadık derecede büyük boyutlar, yanlış sınıflandırmaya işaret edebilir.
