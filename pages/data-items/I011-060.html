I011/060

Mode-3/A Code in Octal Representation Sekizlik Gösterimde Mode-3/A Kodu

Fixed Length — 2 Octets Sabit Uzunluk — 2 Oktet

Purpose Amaç

This data item conveys the Mode-3/A transponder code associated with a track, represented as a four-digit octal number. The Mode-3/A code (commonly called "squawk code") is assigned by air traffic control to identify aircraft on radar displays. In A-SMGCS context, it helps correlate surface tracks with flight plan data. Bu veri öğesi, bir izle ilişkilendirilmiş Mode-3/A transponder kodunu dört basamaklı bir sekizlik sayı olarak iletir. Mode-3/A kodu (yaygın olarak "squawk kodu" olarak adlandırılır) hava trafik kontrolü tarafından radar ekranlarında uçakları tanımlamak için atanır. A-SMGCS bağlamında, yüzey izlerini uçuş planı verileriyle ilişkilendirmeye yardımcı olur.

Note: Unlike CAT048 (radar sensor level), CAT011 does not include V (Validated), G (Garbled), or L (Last Measured) flags in this data item. CAT011 is a fused output — by the time the code reaches this level, the fusion process has already resolved validity and garbling. Not: CAT048'den (radar sensör seviyesi) farklı olarak, CAT011 bu veri öğesinde V (Doğrulanmış), G (Bozuk), veya L (Son Ölçülen) bayraklarını içermez. CAT011 bir füzyon çıktısıdır — kod bu seviyeye ulaştığında, füzyon süreci geçerlilik ve bozulmayı zaten çözmüştür.

Octal Digit Mapping Sekizlik Basamak Eşleştirmesi

Octal Digit Sekizlik Basamak Binary (3 bits) İkili (3 bit) Bit Position Bit Konumu
1st digit (thousands) 1. basamak (binler) xxx Bits 12–10
2nd digit (hundreds) 2. basamak (yüzler) xxx Bits 9–7
3rd digit (tens) 3. basamak (onlar) xxx Bits 6–4
4th digit (units) 4. basamak (birler) xxx Bits 3–1

Each 3-bit group encodes a single octal digit (0–7). The complete squawk code is read left-to-right from MSB to LSB as a four-digit octal number. Her 3 bitlik grup tek bir sekizlik basamağı kodlar (0–7). Tam squawk kodu, MSB'den LSB'ye soldan sağa dört basamaklı bir sekizlik sayı olarak okunur.

Hex Example Onaltılık Örnek

Scenario: Encode squawk code 2617 (a typical discrete code assigned to an aircraft). Senaryo: Squawk kodu 2617'yi kodlayın (bir uçağa atanan tipik bir ayrık kod).

Step 1 — Convert each octal digit to 3-bit binary Adım 1 — Her sekizlik basamağı 3 bitlik ikiliye dönüştürün
2 → 010   6 → 110   1 → 001   7 → 111
Step 2 — Prepend 4 spare bits (0000) Adım 2 — 4 yedek bit ekleyin (0000)
0000 + 010 110 001 111 = 0000 0101 1000 1111
Step 3 — Convert to hexadecimal Adım 3 — Onaltılığa dönüştürün
Octet 1: 0000 0101 = 0x05   Octet 2: 1000 1111 = 0x8F
Step 4 — Final Encoded Value Adım 4 — Son Kodlanmış Değer
Squawk 2617 → 0x058F

Decode verification: 0x058F = 0000 0101 1000 1111. Skip 4 spare bits → 010 | 110 | 001 | 111 → 2, 6, 1, 7 → Squawk 2617 ✓ Çözümleme doğrulaması: 0x058F = 0000 0101 1000 1111. 4 yedek bit atla → 010 | 110 | 001 | 111 → 2, 6, 1, 7 → Squawk 2617 ✓

Well-known codes: Squawk 7700 (emergency) = 0x0FC0, Squawk 7600 (radio failure) = 0x0F80, Squawk 7500 (hijack) = 0x0F40. These codes trigger immediate alerts in A-SMGCS systems. Bilinen kodlar: Squawk 7700 (acil durum) = 0x0FC0, Squawk 7600 (telsiz arızası) = 0x0F80, Squawk 7500 (kaçırma) = 0x0F40. Bu kodlar A-SMGCS sistemlerinde anında alarm tetikler.

Validation Rules Doğrulama Kuralları

Rule Kural Description Açıklama
Spare bits Yedek bitler Bits 16–13 must be zero. Non-zero spare bits should be flagged as a format error. Bitler 16–13 sıfır olmalıdır. Sıfır olmayan yedek bitler biçim hatası olarak işaretlenmelidir.
Digit range Basamak aralığı Each 3-bit group must be in range 0–7. Since 3 bits inherently produce 0–7, this is always valid. Her 3 bitlik grup 0–7 aralığında olmalıdır. 3 bit doğası gereği 0–7 ürettiğinden, bu her zaman geçerlidir.
Code 0000 Kod 0000 Squawk 0000 is technically valid but uncommon in practice. Treat with caution — it may indicate missing or default data. Squawk 0000 teknik olarak geçerlidir ancak pratikte nadirdir. Dikkatli davranın — eksik veya varsayılan veriyi gösterebilir.
Emergency codes Acil durum kodları Codes 7500, 7600, and 7700 are reserved emergency codes. Systems should flag these for immediate attention. Kodlar 7500, 7600 ve 7700 ayrılmış acil durum kodlarıdır. Sistemler bunları acil dikkat için işaretlemelidir.

Important Notes Önemli Notlar

Tip: Mode-3/A codes are only available for targets equipped with a transponder. Surface vehicles without transponders (ground vehicles, equipment) will not have this data item present. The absence of I011/060 in a track record is normal for non-transponder-equipped targets. İpucu: Mode-3/A kodları yalnızca transponder ile donatılmış hedefler için mevcuttur. Transponder olmayan yüzey araçları (yer araçları, ekipman) bu veri öğesine sahip olmayacaktır. Bir iz kaydında I011/060'ın bulunmaması, transponder donanımlı olmayan hedefler için normaldir.

Important: Do not confuse the Mode-3/A code with the Mode-S address (24-bit ICAO address in I011/380). The squawk code is a 4-digit octal number assigned by ATC and can change during a flight, while the Mode-S address is a permanent, globally unique aircraft identifier. Önemli: Mode-3/A kodunu Mode-S adresiyle (I011/380'deki 24 bit ICAO adresi) karıştırmayın. Squawk kodu, ATC tarafından atanan ve bir uçuş sırasında değişebilen 4 basamaklı bir sekizlik sayıdır, Mode-S adresi ise kalıcı, global olarak benzersiz bir uçak tanımlayıcısıdır.
