I011/015

Service Identification Servis Tanımlama

Fixed Length — 1 Octet Sabit Uzunluk — 1 Oktet

Purpose Amaç

Identification of the service provided to one or more users. This data item allows the distinction between different services provided by the same A-SMGCS data source (same SAC/SIC). For example, one service could provide full surveillance tracks while another provides only alert messages. Bir veya daha fazla kullanıcıya sağlanan servisin tanımlanması. Bu veri öğesi, aynı A-SMGCS veri kaynağından (aynı SAC/SIC) sağlanan farklı servislerin ayırt edilmesine olanak tanır. Örneğin, bir servis tam gözetim izleri sağlarken, başka bir servis yalnızca alarm mesajları sağlayabilir.

Key concept: While I011/010 (SAC/SIC) identifies which system is sending, I011/015 identifies which service from that system. A single A-SMGCS server can provide multiple parallel data streams — each with a different Service ID. Temel kavram: I011/010 (SAC/SIC) hangi sistemin gönderdiğini tanımlarken, I011/015 o sistemden hangi servisin olduğunu tanımlar. Tek bir A-SMGCS sunucusu, her biri farklı bir Servis Kimliğine sahip birden fazla paralel veri akışı sağlayabilir.

Important Notes Önemli Notlar

Tip: The Service Identification value is locally defined between the data provider and data consumer. There is no standardized assignment — each A-SMGCS deployment defines its own service numbering scheme. Documentation of the service assignments should be part of the system's Interface Control Document (ICD). İpucu: Servis Tanımlama değeri, veri sağlayıcı ve veri tüketici arasında yerel olarak tanımlanır. Standartlaştırılmış bir atama yoktur — her A-SMGCS kurulumu kendi servis numaralandırma şemasını tanımlar. Servis atamalarının dokümantasyonu, sistemin Arayüz Kontrol Dokümanı (ICD) kapsamında yer almalıdır.

Note: When this data item is absent from a CAT011 message, the receiver should treat all messages from the same SAC/SIC as belonging to a single default service. Multi-service setups require this field to be present for proper data routing. Not: Bu veri öğesi bir CAT011 mesajında bulunmadığında, alıcı aynı SAC/SIC'den gelen tüm mesajları tek bir varsayılan servise ait olarak değerlendirmelidir. Çoklu servis kurulumları, doğru veri yönlendirmesi için bu alanın mevcut olmasını gerektirir.
